

# Algorithm Practice Repository

Welcome to **Adnan Karim's Algorithm Practice Repository**
This collection features categorized implementations of classic algorithmic problems with a focus on:

* Time and space complexity analysis
* Problem-solving patterns (e.g., sliding window, two pointers, recursion)
* Fundamental concepts (e.g., bit manipulation, hashmaps, dynamic programming)

---

## Folder Structure

| Folder/File                      | Description                                                   |
| -------------------------------- | ------------------------------------------------------------- |
| `BitManipulation/`               | Subset generation using recursion and bit manipulation        |
| `Fibonacchi/`                    | Recursive Fibonacci with complexity analysis                  |
| `Generate Substrings/`           | Substring generation with time and space breakdown            |
| `Longest Palindromic Substring/` | Brute-force and optimized LPS solutions                       |
| `MergeIntervals/`                | Merge intervals with recursive permutations                   |
| `Permutations/`                  | Recursive permutation generation                              |
| `Subarrays/`                     | Subarray problems with uniqueness checks (bit manipulation)   |
| `Subsets/`                       | Recursive subsets and longest palindrome subsequence          |
| `TwoSum/`                        | Classic Two Sum with hashmap and complexity analysis          |
| `arrays/`                        | Get third max element with time/space analysis                |
| `bitvector table/`               | Bitwise uniqueness checks                                     |
| `coderbyte/`                     | String manipulation challenges from Coderbyte                 |
| `hashmaps/`                      | Remove duplicates in linked list using hashmap                |
| `linkedlist/`                    | Linked list deduplication logic                               |
| `recursion/`                     | Recursion practice with complexity breakdown                  |
| `slidingwindow/`                 | Efficient substring handling using the sliding window pattern |
| `twopointers/`                   | Two-pointer approach for uniqueness checks                    |
| `findRabbit.js`                  | JavaScript solution for logical rabbit puzzle                 |
| `isPrime.cpp`                    | C++ function to check if a number is prime                    |
